# Оновлення Pi01–Pi04 через GitHub

Спільні виправлення комітяться в main після тестів. Для публікації пакетів створюється явний тег vYYYY.MM.DD.N. GitHub Actions запускає JS/Python тести і створює Release із чотирма пакетами та release.json (commit, hostname, SHA256 кожного файла). Невдала CI не є опублікованим релізом.

## Завантаження на Raspberry

Після перевіреного встановлення tools/pull_update.py на потрібний борт:

```sh
python3 /path/to/pull_update.py v2026.10.15.1
```

Скрипт визначає pi01–pi04 за hostname, завантажує тільки її пакет, перевіряє SHA256 і дозволені шляхи архіву. Не розпаковує в /opt, не запускає отриманий код, не пише параметри польотника і не перезапускає служби. Зберігає в ~/harpoon-updates. Немає фонового poll/timer і автоматичного встановлення. SHA256 забезпечує цілісність; джерелу GitHub/maintainer потрібна довіра, окремого офлайн-підпису немає.

## Встановлення — окремий етап

Це перша версія доставки: **скачування/перевірка готові, універсального apply/rollback ще немає**. Старий install-auditfix.py не приймає ці повні пакети. Не запускати його на них. Перед новим installer потрібні порівняння live baseline, backup, fresh DISARMED/no lease/zero outputs, захист від старту сесії під час install, транзакційна заміна, rollback та health checks. До цього застосовувати тільки окремо перевірене розгортання агентом. Не підміняти файли контролера на ARMED борту.

## Конфіги

Пакети містять застосунок, не /etc/harpoon, не GPSmonitor цілком, не камери, GPSoffset, BMSпорти, маршрути, Tailscaleidentity чи ключі. Відкриті board-specific snapshots — config/pi04, шаблон — config/deployment.example.json. Це довідка, не автоматичне overwrite liveconfig. Нові зміни конфігів потребують окремих версіонованих міграцій із перевіркою попереднього стану. Паролі й приватні адресні журнали не публікувати.

Поточні відмінності політики CRITICAL Pi04 проти Pi01–03 збережені; ця доставка не змінює timeout/failsafe/ARM поведінку. Відомий automatic DISARM при завершенні маршруту ще не змінений. Не називати невиконану правку включеною до релізу.
