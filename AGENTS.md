## Де змінювати код

- Спільне актуальне джерело Raspberry/web: `clones/harpoon-03/pilot-beta/`. Назва Pi03 тут історична: джерело використовується для всіх бортів, але live борти мають власні налаштування.
- `control_service.py`: USB/MAVLink, сесії, перевірка свіжості, виходи.
- `control_runner.py`: інтеграція автомісії, локальний цикл і дії API.

- `live-control.js`, `pad-config.js`: браузерне керування й TX12.
- `beta.js/css`, `navigation.js/css`, `route-editor.js/css`: інтерфейс, прилади, карта й редактор маршруту.
- `clones/harpoon-02/latest-20261014/build.py`: адаптація пакетів для board1–4. Генерація не дорівнює встановленню.
- `app/`, `worker/`, `db/`: окремий Vinext starter, не основний live веб Raspberry. Не використовувати npmdeploy як спосіб оновлення борта.

## Перед розгортанням

1. Визначити конкретний борт, звірити pinnedSSHkey і hostname, прочитати live стан та конфіги.
2. Порівняти файли/хеші; не запускати старий installскрипт за назвою без читання.
3. Зберегти backup і план відкату. Не стирати маршрути, сесії, Tailscale identity, GPSпоправки, camera/BMSконфіги.
4. Перед перезапуском контролера вимагати свіжий DISARMED, відсутність активної сесії й нульові команди. Не виконувати DISARM замість користувача без окремого дозволу.
5. Після встановлення перевірити хеші, служби, HTTPдані й журнали. Не називати ACK або HTTP200 підтвердженням фізичного руху/відео.
6. Не запускати disabledконтролер Pi04 без окремого введення в експлуатацію.

## Тести та відомі пастки

- JS mockтести: `test-live.cjs`, `test-pad.cjs`, `test-switch-start.cjs`, `test-route-editor.cjs` у canonicalпапці.
- Python mockтести керування потребують Linux і pymavlink (імпортують fcntl/termios). Запускати в ізольованому середовищі; не запускати mainслужби чи USB для тестів.
- GPSsource має експортувати position_age_s, heading_age_s, speed_age_s. Новий autonav зі старим GPSmonitor несумісний; старий provisionpayload не вважати актуальним.
- Локальний маршрутний цикл10Гц не означає автономну роботу без браузера. Поточний3секундний timeout обнуляє виходи, зберігає сесію й скасовує місію; explicitrestart потрібний. Hiddenpage/keyboardblur і recordedreturnбездуг залишаються відомими обмеженнями.
- Не змінювати ці політики побіжно під час UI/Gitзадач. Окрема явна задача, тести й опис наслідків обов'язкові.

## Секрети та Git

Не виконувати сліпий git add .: у робочій папці є SDuser-data, архіви, образи, ключі й історичні конфіги. `.gitignore` не видаляє секрети з історії. Перед push перевірити stagedфайли та приватність destination. Важливі скрипти в ignoredwork потребують окремого відбору, не публікувати work цілком. Не змінювати globalGittrust або ACL заради обходу dubiousownership без згоди власника.
